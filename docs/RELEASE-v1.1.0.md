## 1.1.0 · 外观自定义
- 新增“07 外观设置”，提供设施绿／琥珀、深海蓝／冰青、暮光紫／薰衣草、石墨灰／薄荷、酒红／玫瑰金五套配色。
- 支持 PNG、JPG、JPEG、BMP 背景图片，并保存本地副本。
- 新增毛玻璃开关与 0–40 背景模糊强度；文字及输入框保持清晰。
- 内容面板和页眉保留至少 90% 不透明的深色底，保证高亮背景下的可读性。
- 外观自动保存，支持移除背景与恢复默认；图片丢失时回退至内置渐变。
- 保留 1.0.1 的新世界存档修复及现有开服功能。

### 升级
退出旧开服器后替换 EXE，在左侧“07 外观设置”中调整。服务器偏好和外观偏好独立保存。

### 下载
`GateControl.exe` 为单文件程序；`GATE-Control-v1.1.0.zip` 包含源码、说明及测试记录；`SHA256.txt` 用于校验 EXE。
